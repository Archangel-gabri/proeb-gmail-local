# Gmail Local — public pages

Privacy policy and terms of use for a private Gmail integration that runs on the owner's own computer.
It uses the open-source [gogcli](https://github.com/openclaw/gogcli) client and Google's Gmail API to search,
read and organise the owner's mail on request, and exposes it to the owner's assistant through a local MCP
interface.

- Home: <https://archangel-gabri.github.io/proeb-gmail-local/>
- Privacy policy: <https://archangel-gabri.github.io/proeb-gmail-local/privacy.html>
- Terms of use: <https://archangel-gabri.github.io/proeb-gmail-local/terms.html>

This repository holds only these static pages. There is no code, mail or credentials here, and the pages do
not connect to Gmail or receive OAuth callbacks. Not affiliated with or endorsed by Google.
