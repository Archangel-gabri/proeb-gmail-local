Privacy policy

Effective September 22, 2026. This policy describes the personal, owner-operated PROEB Gmail Local desktop integration. There is no public hosted application collecting other people's mail.

Access and purpose

With the account owner's Google OAuth authorization, the integration can access the account email address, message headers and bodies, threads, labels, and basic Gmail settings and filters. Data is used only for the owner's requested search, review, and organization tasks.

The requested Gmail permissions are gmail.readonly, gmail.modify, and gmail.settings.basic, together with basic account identity permissions. Google's gmail.modify permission also technically permits composing and sending messages; the local sorting wrapper disables sending. The integration does not request mail forwarding/delegation permissions or the full-mail scope that allows immediate permanent deletion.

Storage and security

OAuth client secrets and refresh tokens are stored in the owner's operating-system wallet. Non-secret account and client configuration is kept locally with owner-only access. The public documentation website stores no email, OAuth secrets, or Google passwords. The integration has no cloud mailbox database.

Requested exports, local task notes, or assistant conversation records may remain in the owner's configured workspace or chosen assistant service. Their retention follows the owner's settings and the relevant service's policy. Avoid exporting unnecessary sensitive information.

Sharing and AI-assisted work

Mail is not sold, used for advertising, or shared with unrelated parties. When the owner explicitly requests AI-assisted review or organization, only the relevant content needed for that task may be provided to the owner's selected assistant provider. Such use must remain compatible with the Google API Services User Data Policy and its Limited Use requirements.

The integration does not use Google user data to train generalized AI or machine-learning models. It does not grant an assistant independent permission to publish, send, or delete mail. The owner controls requested actions and the services used for processing.

Control, retention, and removal

The owner can disconnect at any time through Google Account connections. Removing the local gogcli account credentials also removes its stored authorization. Previously exported files or assistant conversations must be deleted separately in their respective locations. Disconnecting does not delete the original Gmail mailbox.

Website and contact

These documentation pages contain no application analytics, cookies, forms, or third-party scripts. GitHub Pages may process normal hosting access data under GitHub's privacy statement. Questions can be raised in the documentation repository; never include private mail or credentials.

Use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.
